# Cursor-Inspired Developer Tool Landing Page

## Overview

This project recreates a **desktop-first developer tool landing page inspired by the Cursor website**, built using only **HTML and CSS** as part of the **Web Dev Cohort 2026 evaluation**.

The focus of this assignment is **visual and structural accuracy**, not creativity or interactivity. The goal was to match the original design as closely as possible in terms of layout, spacing, typography, colors, and overall visual hierarchy.

---

## Tech Stack

* HTML5 (Semantic HTML)
* CSS3

**Restrictions followed:**

* No JavaScript
* No TailwindCSS
* No AI usage
* No animations or fancy effects
* Desktop-only (no responsiveness)

---

## Objective

* Recreate a developer tool landing page inspired by Cursor
* Match page structure, layout, and spacing accurately
* Use fonts and colors close to the reference design
* Write clean, readable, and semantic HTML

---


### Fonts

* Primary font: **Inter**
* Fallback: system sans-serif fonts

Font weights and sizes were chosen to closely match the Cursor website’s typography and hierarchy.

## HTML Structure

* Semantic elements used throughout (`header`, `nav`, `section`, `article`, `footer`)
* Clean and minimal class names
* Clear section separation for readability
* No unnecessary wrappers
